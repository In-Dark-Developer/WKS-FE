# 기획

<aside>

디자인·기획 컨셉 : 부처가 점지해준 나의 운명

십이간지 활용 (생년월일에 따른), 언어는 ‘보살’ 로

</aside>

**사용자에게 받을 정보** : **생년월일, 시간 입력, 태어난 지역, 성별, 닉네임 (시간, 지역은 모름 가능)**

이메일 학교 인증, 이름, 연락처 (인스타,전번), 사진, 학과, 나이, MBTI, 자기소개 - 추가 정보임

1,2번에서 3번 전환할 때 소개팅 위해 필요한 정보 입력 (ai 프롬포트 잘 구성해놓기 - 만세력 활용?)

사주는 **연애, 재물, 학업, 축제 기간 아이템, 운** 으로 제공 (제공 후 하단 링크 공유 버튼) - 링크 통해서 활용시 사주 체크 후 내 페이지에 점수로 표기 

인스타 바로 공유 - 카드 업로드 가능

<aside>

친구 점수 표기 방법

- 25점 구분 표기 (귀인 - 찰떡 - 벗 - 스침)
</aside>

하단 소개팅은 블러 처리로 미리 표기 (정보 등록하고 동의 후 알림 신청하기) ⇒ 신청 시 1회 쿠폰 지급

<aside>

디자인 필요한 부분 : 디자인 시스템 (영채)

**인트로 영상** - 문구와 버튼 삽입 - 인당 하나씩

사주 결과 화면 (링크 공유, 인스타 공유 버튼, 배경) **(선우)**

점지 카드 디자인 (인스타 공유용) - 십이간지 활용한 캐릭터 + 수치 + 바이럴 잘되게 **(진희)**

친구 점수 보여주는 섹터 (귀인 - 찰떡 - 벗 - 스침) : 구슬 꿰매기 **(영채)**

블러 처리 위 모달 (정보 입력 인풋 필드), 정보 입력 버튼 - 인풋 필드 위주로, 최종 CTA, 배경 **(유민)**

</aside>

버튼 통해 정보 입력 시 블러 삭제 ⇒ 점지 카드 확인 가능 (점지 카드 정보에는 내가 입력한 정보들만 상대방의 정보를 확인 가능)

유료 ⇒ 돈 계산은 도윤님

카드에 정보가 뜨고, 정보를 보려면 결제가 필요, 정보 확인 후 운명의 실 보내기 버튼 , 버튼 클릭 시 상대방에게 보임, 상대방도 운명의 실 당기기
