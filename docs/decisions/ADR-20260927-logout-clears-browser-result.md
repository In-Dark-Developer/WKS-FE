# ADR-20260927: 로그아웃하면 이 브라우저의 '내 결과'(`wks:session`)도 지운다

- Status: Accepted
- Date: 2026-09-27
- Deciders: @jjjung0921 (제안) / 리뷰어는 PR 승인자

## Context

ADR-20260914-result-ownership-in-browser 로 '내 결과'는 localStorage `wks:session` 의 `resultId` 하나이고 로그인과 무관하다. 로그아웃(`POST /auth/logout`)은 백엔드가 쿠키 `wks_token` 을 만료시킬 뿐이라, 로그아웃해도 홈(`/reading/:id`)·궁합 지도에 결과가 그대로 남는다.

로그인은 계정 결과를 이 브라우저에 덮어쓴다(FR-21, `completeKakaoLogin` 의 `writeSession(restoredResultId)`). 축제에서 친구 기기로 로그인했다가 로그아웃하면 계정의 결과·궁합 목록·공유 링크가 그 기기 홈에 남는다. 로그아웃 뒤 브라우저 기록을 어떻게 할지는 PRD·ADR 에 정해져 있지 않았다.

## Problem

로그아웃할 때 이 브라우저의 '내 결과'를 남길 것인가.

## Alternatives

1. **로그아웃 성공 시 `wks:session` 을 지운다** — 가장 단순하다. 로그인 전 비로그인으로 만든 결과도 이 브라우저에서 사라진다.
2. **로그인이 덮어쓴 경우에만 원래 브라우저 결과로 되돌린다** — 비로그인 기록을 지키지만 로그인 전 값을 따로 보관해야 한다.
3. **그대로 둔다** — 공용 기기에 계정 결과가 남는다.

## Decision

대안 1. `src/api/auth.ts` `logout` 이 성공 응답(목 모드 포함) 뒤 `clearSession()` 을 부른다. 실패하면 로그인 상태가 그대로이므로 지우지 않는다.

## Rationale

- 결정적 기준은 공용 기기에서 계정 결과가 남지 않는 것과 축제(2026-09-29 ~ 10-01) 전 일정이다. 대안 2 는 보관 값과 경우의 수가 늘어난다.
- 로그인하면 브라우저 결과가 계정에 연결되거나(계정이 비었을 때) 계정 결과가 복원되므로, 대부분은 다시 로그인해 되찾을 수 있다.

## Consequences

- 긍정: 로그아웃 뒤 홈·궁합 지도가 사주 입력으로 안내되고, 계정 결과가 기기에 남지 않는다.
- 부정 / 감수한 것: 계정에 이미 다른 결과가 있어 연결되지 않은 비로그인 결과는 로그아웃 뒤 이 브라우저에서 되찾을 수 없다(백엔드에는 남아 있고 주소를 알면 열린다).
- 후속 작업: 없음
