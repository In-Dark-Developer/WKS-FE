인트로(SCR-01)는 디자인 없이 영상만 전달받아 2026-09-14 범위에 넣었다 — 문구·시작 버튼은 없다.

V1 흐름(2026-09-22 기획 개정, Figma `imSnlOGTqwtPhGyzhA8yc9`): 티저(SCR-01) → 사주 입력(SCR-02) → 로딩(SCR-03) → **사주 결과 = 홈**(SCR-04). 홈부터 하단 네비게이션(홈·궁합지도·소개팅)이 붙는다. 궁합지도(SCR-08)는 로그인 없이 열리고 저장·복원에만 로그인이 필요하다(SCR-22). 소개팅은 인트로(SCR-15) → 로그인 → 프로필 등록(SCR-16) → Top 3 카드(SCR-17) → 해금(SCR-18) → 운명의 실(SCR-19) → 요청함(SCR-20)으로 이어진다. 공유 Flow 진행 중에는 하단 네비를 노출하지 않고, '내 사주 내용도 확인하기'로 홈에 들어온 시점부터 노출한다.

SCR-05·SCR-07 은 V0.5 에서 이미 없어진 자리이고, SCR-10·SCR-11(구 소개팅 후보·운명의 실)은 V1 의 SCR-17·SCR-19 가 대신한다. SCR-09(사전신청 모달)·SCR-14(인증 완료)는 V0.5 운영본에만 남는다 — V1 플로우는 카카오 로그인을 쓴다.

공유 링크 흐름(2026-09-15 소유자 확인, 같은 날 입력 먼저로 개정): 링크 주인이 궁합 지도(SCR-08)의 '친구에게 공유하고 궁합 지도 넓히기'로 `/s/:shareId` 를 보낸다 → 받은 사람은 첫 방문이면 인트로(SCR-01) 뒤 SCR-06 에서 사주를 입력한다. 이 브라우저에 내 결과가 이미 있으면 입력을 건너뛴다 → '운명 지도 확인하기' → 결과 대기(SCR-03) → 결과 생성 → 궁합 생성 → SCR-13 에서 링크 주인의 궁합 지도(내가 들어간)를 본다 → '내 사주 내용도 확인하기' → 자기 결과(SCR-04). 궁합은 두 사람 결과의 `compatibilities` 에 모두 들어가 양쪽 순위·지도에 보인다.
