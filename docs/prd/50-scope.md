# PRD 5 — 제약·비목표·미해결 질문

- Status: Draft
- Last updated: 2026-09-23

## Constraints

- **일정: MVP(채팅 제외, 백엔드 API 연결 포함) 개발 완료 2026-09-17. 축제는 2026-09-29 ~ 10-01.** 9-17이 모든 Phase의 마감이고, 9-18 ~ 9-28은 실기기 검증·운영 준비 기간이다.
- **소개팅 후보·운명의 실 화면(SCR-10·11)은 축제 당일 2026-09-29에 연다.** 사전신청 폼(SCR-09)은 그 전에 미리 열어 두고, 작성·동의 완료가 상대 정보 열람권이다(2026-09-13 기획 피드백).
- **'내 결과'는 이 브라우저가 만든 사주 결과의 `resultId`로 식별한다(2026-09-14 결정 — 2026-09-13 '백엔드 세션 토큰' 결정을 대체).** 백엔드는 사주·궁합에 인증을 두지 않고 세션 토큰을 발급하지 않는다 — 추측할 수 없는 링크 키(`resultId` 본인용 · `shareId` 공개용, UUIDv4)만 쓴다. 프론트는 결과를 만들 때 받은 `resultId` 하나를 브라우저에 보관하고, 결과·인연카드 화면은 그 브라우저에서만 연다. 로그인·비밀번호는 없다. '내 신청·내 실'의 식별은 해당 API 계약(Q3·Q14)을 따른다(ADR-20260914-result-ownership-in-browser).
- **디자인(「UI 최종 - 개발용」)과 기획서(`docs/product-brief.md`) 어디에도 없는 사항은 미정이다.** 이 문서가 임의로 정하지 않고 '미정'으로 표기한다. 백엔드 계약은 2026-09-13에 공개됐고 `docs/api/openapi.yaml`이 그 참조본이다. 계약이 디자인·이 문서와 어긋나는 항목은 지우지 않고 Q3·Q14로 백엔드에 요청 중이다.
- 이 저장소는 프론트엔드 전용이다. 서버 API·DB·사주(만세력) 계산·LLM 문구 생성·궁합 점수·등급은 별도 백엔드 저장소가 소유한다.
- 디자인은 Figma를 따른다: https://www.figma.com/design/tzWb3S2guXz5zH2DMeX8Yt/ — 디자인시스템 `16-2`, 「UI 최종 - 개발용」 `558-2430`, 「기능명세서」 `560-2`. 디자인과 이 문서가 어긋나면 디자인이 우선하고, 이 문서를 디자인에 맞춰 고친다. 2026-09-13 기획 피드백이 디자인과 다르면 피드백이 우선하고 디자인을 고친다.
- 본문 폰트는 Pretendard. 조달 방식(번들 vs CDN)은 Phase 02 T1에서 정한다.
- 콘텐츠 톤은 '보살' 화법("○○보살님이 당신의 운명을 점지했어요"), 소재는 십이간지로 고정한다. 캐릭터 문구는 동물별로 치환한다(디자인의 '돼지보살님'은 예시).

## Non-goals

- 앱 내 1:1 채팅 — 2026-09-13에 아예 제외로 확정. 매칭 성립 시 연락처(전화번호·인스타그램 아이디) 교환으로 대신한다.
- 결제(상대 정보 열람 유료화) — 후속 Phase로 미룬다.
- 쿠폰 지급 안내(FR-11) — 디자인 없음.
- 기획 메모의 재물·학업·축제 아이템 영역 — 디자인이 연애운·결혼운·자녀운 + 행운의 장소·아이템으로 확정했다.
- 나이 입력 — 디자인의 사전신청 모달에 없다. 학교 이메일 인증은 디자인에는 없으나 백엔드 계약(`/signups/verify` 매직링크)에는 있다 — Q14.
- 네이티브 앱, 운영자용 관리 도구, 다국어.
