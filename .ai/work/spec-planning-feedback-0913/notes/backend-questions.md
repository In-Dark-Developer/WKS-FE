# 백엔드 문의·요청 목록 — api-spec.md(2026-09-13) 기준

원칙: openapi 참조본은 백엔드 계약 그대로 둔다. 디자인·PRD(디자인 우선 + 2026-09-13 기획 피드백)에 있으나 계약에 없는 것은 여기 모아 백엔드에 요청한다. 답이 오면 `docs/api/openapi.yaml`과 PRD Open Questions(Q3·Q7·Q12~)를 고친다.

| # | 요청 | 근거 | 없으면 |

| A6 | 개발 서버 포트·CORS origin 확인 (문서는 `localhost:3000`, 프론트 Vite 기본은 5173) | 로컬 연동 | 로컬에서 호출 불가 |
