# agent-memory — 역할별 프로젝트 전용 메모리

전문 역할 에이전트(설계·리뷰 등, 이 저장소의 `.claude/agents/git-flow` 포함)가 **이 프로젝트에서** 배운 것을 두는 곳. 역할의 정의·실행 방식은 각자의 도구 설정이 소유하고, 이 폴더는 그 역할들이 공유하는 **기억의 위치와 형식만** 정한다.
**git이 추적하지 않는다** — 이 README만 추적하고 메모리 파일은 `.gitignore`로 제외된다(`.ai/local/`과 같다). 역할 에이전트를 쓰는 사람의 기계에만 쌓이며 팀에 전달되지 않는다. 역할 에이전트를 쓰지 않는다면 이 폴더는 비어 있는 것이 정상이고, 아무것도 하지 않아도 된다.
팀이 이 메모리를 공유하기로 하면 `.gitignore`의 두 줄을 지우고 `.gitattributes`에 `merge=union`을 되살린 뒤 `AGENTS.md` Rule 9·15를 되돌린다.

## 형식

```text
.claude/agent-memory/<역할>/
├── MEMORY.md       # 인덱스 — 한 줄 링크만, 100줄 상한
├── decisions.md    # 결정과 기각한 대안
├── feedback.md     # 개발자 교정
├── conventions.md  # 문서에 없는 관용구·제약
└── history.md      # 산출물 인덱스 · 반복 실패 패턴
```

`MEMORY.md`는 인덱스다 — 본문을 쓰지 않는다.

```text
# fe-architect memory — 운꿰사 프론트엔드
- [Decisions](decisions.md) — 공유 카드 이미지 클라이언트 생성, 전역 스토어 보류 (2건)
- [Feedback](feedback.md) — ui 컴포넌트에 도메인 규칙 넣지 말 것 (1건)
```

토픽 파일 항목은 **사실 → Why → How to apply** 순서로 쓰고 날짜는 절대 날짜(YYYY-MM-DD)로 적는다.

```text
## 점지 카드 이미지를 클라이언트에서 만든다 (2026-09-11)
서버 렌더 대신 캔버스 생성. 기각: 서버 OG 이미지(백엔드 저장소 소관), 정적 이미지(수치 표기 불가).
Why: SPA라 서버 런타임이 없다.
How to apply: 카드 관련 신규 작업은 src/lib 의 이미지 생성기를 먼저 본다.
```

## 무엇을 적나

- **적는다** — 결정과 기각한 대안, 개발자 교정(규칙 + Why + 적용법), 레포를 읽고 추론해야 알 수 있는 관용구·제약, 반복 실패 패턴, 이전 산출물의 경로와 한 줄 요지.
- **적지 않는다** — 파일을 읽으면 나오는 사실(스키마·시그니처·설정값), `AGENTS.md`·PRD 본문, 이번 호출에만 유효한 상태, 비밀값·개인정보.
- 한 사실은 한 곳에. 결정에 ADR이 있으면 ADR 번호만 적고 내용을 복제하지 않는다.

## 언제 쓰나

- **역할 에이전트**: 시작 시 자기 폴더의 `MEMORY.md`를 읽는다. 메모리와 레포가 다르면 레포가 진실이니 그 줄을 그 자리에서 고친다. 종료 전 이번에 새로 배운 것만 토픽 파일에 적고 인덱스를 갱신한다 — 빈 갱신 금지. 다른 역할의 폴더는 읽지도 쓰지도 않는다.
- **개발자**: 읽어도 되지만 손으로 고치지 않는다. 틀린 기억은 내 스트림 `INBOX.md`에 적으면 다음 호출에서 역할이 고친다.
- 개인의 취향·교정·내 환경은 여기가 아니라 `.ai/local/MEMORY.md`에 둔다. 여기에는 이 프로젝트의 사실만 남긴다.
- 팀이 알아야 하는 결정은 메모리에 묻어두지 않는다 — ADR·`HANDOFF.md`·PR 본문으로 올린다. 여기는 다음 호출이 덜 헤매기 위한 기록이다.

source of truth가 아니다 — `AGENTS.md` Truth 순서에서 ⑪이고 spec·ADR이 우선한다. 메모리를 근거로 레포 확인을 건너뛰지 않는다. 메모리 위치는 에이전트를 실행한 디렉터리 기준이므로 세션은 이 저장소 루트에서 연다.
